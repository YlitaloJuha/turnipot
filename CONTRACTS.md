# Turnipot — component contracts

Root: the repository folder (it may contain spaces — always quote paths).
Build: `swift build` (debug) / `swift build -c release`. Tests: `swift run turnipot-selftest`.
Swift 6.4 toolchain, **Swift 5 language mode** (`swiftLanguageModes: [.v5]`), macOS 14 target.

## Toolchain gotchas (Command Line Tools only, verified)
- `@State` is a macro in this SDK and **does not compile** (SwiftUIMacros plugin missing). Use
  `@StateObject private var x = LocalState(initial)` (`Sources/Turnipot/Views/LocalState.swift`), read `x.value`, bind `$x.value`.
  `#Preview`, `@Entry` also unavailable. `@StateObject/@ObservedObject/@FocusState/@GestureState/@Namespace/@Environment/@AppStorage/@Binding/@Observable` work.
- **XCTest and swift-testing are unavailable.** Tests live in executable target `turnipot-selftest`
  (`Sources/turnipot-selftest/`). Helpers in main.swift: `check(_ name, _ cond)`, `expectEqual(a, b, name)`.
  Each component owns one file: `TranscriptTests.swift` (`registerTranscriptTests()`), `UsageTests.swift`,
  `SessionTests.swift`, `AppStateTests.swift`, `GuardTests.swift`, `DistributionTests.swift`, `SubagentTests.swift`, `TurnipTests.swift`, `AttentionTests.swift`, `ReplyTests.swift`, `HostTests.swift`, `HapticsTests.swift`, `QuestionTests.swift` (also runs the built `.build/debug/turnipot-hook` against a fake app socket; skipped if not built). main.swift calls each register function.
  AppState is @MainActor: wrap in `MainActor.assumeIsolated { }` inside register function (selftest runs on main thread).
- Don't change public signatures below without updating this file; other agents code against them.
- Never touch: ~/.claude/settings.json, ~/.vscode-oss, user's Claude sessions.

## NotchCore/TerminalBridge.swift
- `enum NativeTerminal { appleTerminal, iTerm2 }` (NativeTerminals.swift) — `bundleId`, `displayName`, `init?(bundleId:)` (case-insensitive); `struct Location { appPath, bundleId?, tty?; terminal }`; `static hostAppPath(ancestorPaths:) -> String?` (outermost `.app` of the nearest ancestor inside a bundle), `static locate(pid:ancestorPaths:) -> Location?`, `static ttyPath(pid:) -> String?` (`/dev/ttysNNN`), `static sanitizedReply(_:)` (newlines -> spaces, C0/C1 controls dropped), `static replyPayload(_:)` = `ESC[200~` + sanitized + `ESC[201~` + CR (the bytes either terminal receives), `static appleScriptLiteral(_:)` (sanitized, `\\` and `"` escaped); `focusScript()` / `sendScript(reply:)` (AppleScript for `osascript - <tty>`, the reply embedded as a literal; print `ok` / `missing`); `enum ScriptResult { ok, missing, notAuthorized, failed }`, `static runScript(_:arguments:timeout: = 60)`, `static parseResult(status:stdout:stderr:)` (-1743 / -10004 -> notAuthorized).
- Routing (`TerminalBridge(runtimeDir:sendGate:desktopActivator:locator:scriptRunner:opener:)`, the last three injectable): focus — Terminal / iTerm2 location: focus script (if tty known) then `open -b <bundle id>` (always true, also when the script fails); else extension broadcast (answering editor activated); else `open -a <appPath>` of the located app; nothing located -> false. send — after the dialog gate and the foreground-job check: Terminal / iTerm2: `sendScript(reply:)` (true iff `.ok`; no tty -> false); else extension broadcast; other apps never get typed into.

```jsonc
// permission allow / always allow
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow",
  "updatedPermissions":[{"type":"addRules","rules":[{"toolName":"Bash","ruleContent":"npm test:*"}],"behavior":"allow","destination":"localSettings"}]}}}
// deny
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"deny","message":"The user denied this tool call from Turnipot."}}}
// AskUserQuestion answered: original input echoed + answers (question text -> label; multi-select "A, B"; Other = typed text)
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow","updatedInput":{
  "questions":[{"question":"Which framework?","header":"Framework","options":[{"label":"React","description":"Component library"},{"label":"Vue","description":"Progressive framework"}],"multiSelect":false}],
  "answers":{"Which framework?":"React"}}}}}
// ExitPlanMode approved (input as hooks receive it: plan + planFilePath injected by Claude Code), then switch mode for this session
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"allow",
  "updatedInput":{"plan":"## Refactor auth\n1. Extract...","planFilePath":"/Users/.../plans/refactor-auth.md"},
  "updatedPermissions":[{"type":"setMode","mode":"default"|"acceptEdits"|"auto","destination":"session"}]}}}
// ExitPlanMode "Keep planning…": deny with the user's feedback (Claude stays in plan mode)
{"hookSpecificOutput":{"hookEventName":"PermissionRequest","decision":{"behavior":"deny","message":"The user wants to keep planning (answered from Turnipot). Stay in plan mode and revise the plan. The user said:\n<feedback>"}}}
```
Docs quote: "Returning `"allow"` alone is not sufficient for these tools." `answers`: "Maps question text to the selected option label. Multi-select answers join labels with commas. Claude doesn't set this field; supply it via `updatedInput` to answer programmatically."
